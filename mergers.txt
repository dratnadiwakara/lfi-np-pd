# lfi-np-pd merger list - drives the pro-forma liability bridge.
#
# Why this file exists: on the day an acquisition closes, the acquirer's share
# count (and so its market cap) jumps to the combined company, but total_liab
# stays on the acquirer's last solo Y-9C until the next quarter lands. E_scaled
# = market_cap / total_liab then divides a combined numerator by a solo
# denominator and the PD reads too low for up to a quarter. Each line here adds
# the target's own last-filed liabilities for exactly those in-between weeks.
#
# Format - one deal per line:
#   <acquirer_rssd>  <target_rssd>  close=YYYY-MM-DD  [liab=<thousands USD>]
#
#   target_rssd  RSSD of the acquired entity in the Y-9C panel. Its last
#                filing on or before close= is what gets added.
#   close=       deal completion date (not announcement).
#   liab=        explicit target liabilities, in thousands, overriding the
#                lookup. Needed when the target files no Y-9C (brokers, asset
#                managers) or when the filed entity is not the entity acquired.
#                Use target_rssd 0 together with liab= when no filer exists.
#                Always say where the number came from in the comment.
#
# Only material deals belong here: below roughly 4% of the acquirer's
# liabilities the distortion is smaller than the rounding on the number being
# read. Cash-only deals do NOT belong here at all - with no shares issued there
# is no equity re-base, so there is no mismatch to correct (PNC/BBVA USA 2021,
# JPM/First Republic 2023, USB/Union Bank 2022 are all correctly absent).
# Neither do capital raises, which have no target: BAC's 2017 Berkshire warrant
# exercise, RF's 2012 TARP repayment offering, MS's 2011 MUFG conversion, STT's
# 2021 offering and KEY's 2024-25 Scotiabank investment all stay
# issuance_bs_lag flags, which is the honest outcome.
#
# Every line is machine-checked by tests/test_merger_bridge.py, which compares
# (acquirer last solo filing + target last filing) against what the acquirer
# actually filed the quarter after the close. A wrong RSSD or a wrong date
# fails loudly there rather than quietly biasing a PD. The error shown against
# each line below is that check's output. It is not pure bridge error: it also
# contains whatever the acquirer's own balance sheet did that quarter, which is
# why Schwab and Morgan Stanley - both of which grew heavily in Q4 2020
# independent of their deals - sit furthest from zero.
#
# Edit this file, then re-run:  lfinp update
