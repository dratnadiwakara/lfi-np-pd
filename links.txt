# lfi-np-pd link overrides - permco -> RSSD from a quarter end onward.
#
# Why this file exists: the panel picks each week's balance-sheet filer from
# the CRSP-FRB link table (ASOF on permco, quarter_end). When a listed
# company's filer changes and the vendor link does not follow, the link keeps
# an RSSD that no longer files. The Y-9C ASOF join then forward-fills the last
# filing indefinitely, the Call Report fallback never triggers (the dead RSSD
# files nothing there either), and only bs_stale notices. Each line replaces
# the vendor's rows for that permco from from= onward.
#
# Format - one permco per line:
#   <permco>  <rssd>  from=YYYY-MM-DD   # where the fact comes from
#
#   from=  first quarter end the new RSSD files for. Must be a quarter end.
#
# If the vendor later links the new RSSD to another permco, the scope build
# sees one RSSD on two permcos and aborts; delete the line here then.
#
# Edit this file, then re-run:  lfinp init
